# うたのわ Legal Pages

This repository hosts the public Privacy Policy and Support pages for the app
`うたのわ`.

## Public URLs

After GitHub Pages is enabled for branch `main` and folder `/docs`, use these
URLs for store submission:

- Privacy Policy: `https://97jnjp-rgb.github.io/app-legal-pages/`
- Privacy Policy alias: `https://97jnjp-rgb.github.io/app-legal-pages/privacy/`
- Support: `https://97jnjp-rgb.github.io/app-legal-pages/support/`

## Pages Setup

GitHub Pages should use:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`
