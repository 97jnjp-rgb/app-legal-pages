うたのわ プライバシーポリシー

最終更新日: 2026年6月1日

このページは、カラオケ記録・友達ゲームアプリ「うたのわ」のプライバシーポリシーとサポート窓口をまとめたものです。

プライバシーポリシー サポート サポート専用ページ

1. 基本方針

うたのわは、ユーザーが入力したカラオケの曲メモ、点数、キー、セッション記録、友達ゲーム結果を端末内に保存するアプリです。 初期版ではアカウント作成、ログイン、クラウド同期、位置情報取得、マイク利用、音源再生、録音、歌詞表示、公式カラオケサービス連携を行いません。

2. 収集する情報

初期版のうたのわは、開発者のサーバーへ個人情報を送信・収集しません。

アプリ内でユーザー操作により端末内へ保存される情報は次のとおりです。

  • 曲メモ: 曲名、歌手名、点数、キー、機種、メモ、分類、タグなど
  • セッション記録: 開始日時、終了日時、歌唱履歴、曲数、最高点、平均点など
  • 参加者情報: 友達ゲームで使う表示名やメモ
  • ゲーム結果: ゲーム種別、手入力点数、順位、結果メタデータなど
  • 共有カード: 結果メタデータから生成したPNG画像
  • CSVインポート用データ: ユーザーが取り込んだ曲メモCSVの対象列

3. 収集しない情報

うたのわは初期版において、次の情報や機能を扱いません。

  • 歌詞本文の保存、表示、抽出、検索
  • 音源の保存、再生、解析
  • 録音、録音共有、音声分析
  • DAM、JOYSOUND等の公式カラオケサービスとの連携、スクレイピング、公式採点の取得や再現
  • ログイン情報、アカウント情報、クラウド同期データ
  • 位置情報、マイク入力、広告ID

4. 情報の利用目的

端末内に保存される情報は、次の目的で利用されます。

  • 曲メモ、点数、キー、歌いやすさなどを表示・編集するため
  • カラオケセッションの履歴や集計を表示するため
  • 友達ゲームの進行、結果表示、保存済み結果の確認を行うため
  • 共有カードPNGやCSVテンプレートをユーザー操作により生成・保存するため
  • アプリ内の全削除機能により、ユーザーデータを削除するため

5. 保存場所と送信

ユーザーが入力した情報は、端末内のアプリ管理領域に保存されます。 初期版では、開発者が管理するサーバー、クラウドストレージ、外部分析サービスへ送信しません。

共有カードは、曲名、点数、参加者名、順位、日付などの結果メタデータから生成されるPNG画像です。 共有カードには歌詞、音源、録音データを含めません。OS共有を利用する場合も、共有対象はユーザー操作で生成されたPNG画像のみです。

6. 第三者提供

うたのわは、初期版ではユーザー情報を第三者へ販売、共有、提供しません。 ユーザーが端末の共有機能を使って共有カードを送信した場合、その送信先での取り扱いは送信先サービスの規約とプライバシーポリシーに従います。

7. 広告・課金

初期版では広告SDKとアプリ内課金を実装していません。 将来、広告や広告フリー機能を追加する場合は、利用するSDK、取得される可能性のある情報、ストア申告、同意表示を確認し、本ポリシーを更新します。

8. データ削除

アプリ内の全削除機能により、曲メモ、セッション、歌唱履歴、参加者、ゲーム結果、共有カード、CSVテンプレートなどのアプリ管理データを削除できます。 また、端末からアプリをアンインストールすることでも、通常はアプリ管理領域のデータが削除されます。

9. 子どものプライバシー

うたのわは、初期版では開発者のサーバーへ個人情報を収集しません。 友達ゲームの参加者名には、本名ではなくニックネームを使うことをおすすめします。

10. 免責と注意事項

うたのわはDAM、JOYSOUND等の公式カラオケサービスではありません。 歌詞表示、音源再生、録音共有、公式採点、公式履歴連携、スクレイピングは提供しません。 点数はユーザーが手入力する記録であり、公式採点結果の取得や再現ではありません。

11. ポリシーの変更

機能追加、法令、ストア要件、利用SDKの変更に応じて、本ポリシーを更新することがあります。 重要な変更がある場合は、アプリ内または本ページで分かりやすくお知らせします。

12. サポート・お問い合わせ

不具合報告、削除方法、プライバシーに関するお問い合わせは、次のページからご連絡ください。

GitHub Issuesで問い合わせる

GitHubアカウントがない場合は、各ストアに表示されるデベロッパー連絡先をご利用ください。 お問い合わせ時は、端末名、OSバージョン、アプリバージョン、発生した画面、再現手順を添えていただくと確認がスムーズです。
