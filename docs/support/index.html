お問い合わせ

不具合報告、削除方法、プライバシーに関するお問い合わせは、問い合わせフォームからご連絡ください。

問い合わせフォームを開く

GitHub Issuesでは、サポート、プライバシーに関するお問い合わせ、不具合報告を受け付けていません。 お問い合わせは問い合わせフォームをご利用ください。

問い合わせ時にあると助かる情報

  • 返信用メールアドレス
  • 端末名
  • OSバージョン
  • アプリバージョン
  • 発生した画面
  • 再現手順
  • 期待した動きと実際の動き

歌詞、音源、録音データ、パスワード、住所、電話番号などの機微な情報は送信しないでください。

データ削除

アプリ内の全削除機能により、曲メモ、セッション、歌唱履歴、参加者、ゲーム結果、共有カード、CSVテンプレートなどのアプリ管理データを削除できます。 また、端末からアプリをアンインストールすることでも、通常はアプリ管理領域のデータが削除されます。

注意事項

うたのわはDAM、JOYSOUND等の公式カラオケサービスではありません。 歌詞表示、音源再生、録音共有、公式採点、公式履歴連携、スクレイピングは提供しません。
